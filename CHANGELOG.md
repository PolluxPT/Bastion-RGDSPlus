# Changelog

## 1.0.0-beta.1 — Beta 1

- Freeze the working Alpha1.5 gameplay/scheduling, controls, texture, audio and performance settings.
- Rename support folder to Bastion_RGDSPlus and main launcher to Bastion.sh.
- Consolidate all redistributable runtime/port dependencies into a clean-install release.
- Prepare the owner's original Linux assembly locally, with backup, supported-build checking and idempotent existing-Alpha detection.
- Keep saves/calibration local and preserve them through a documented upgrade path.
- Add licence inventory, public-package audit, release checksums and GitHub publishing instructions.
- Keep supplied artwork confined to the personal install; public assets contain no game/art files.

Known: heavy battles can still run slowly/in slow motion; full playthrough and additional builds/firmware are not fully validated. This is a Beta, not a Final release.
