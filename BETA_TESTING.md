# Beta 1 testing checklist

- Clean install from the public release plus a legally obtained supported Linux game.
- Upgrade an Alpha1.5 installation without losing saves or calibration.
- Cold boot, Continue, save, quit and Continue again.
- Several map-to-level transitions and different environments.
- Small and large battles, bosses, weapon changes and special abilities.
- Cutscenes, narration, music and physical volume adjustment.
- Main menus and in-game action remapping, including both triggers.
- Exit through the game menu and by START+SELECT.
- Confirm OS volume, lower-screen brightness and CPU/GPU governors return to their previous values.
- Long sessions; note crashes, thermal/clock changes and slow-motion situations.

A complete playthrough, especially late-game/final encounters, is desirable before a Final label. Track unresolved issues rather than declaring unsupported builds or 60 FPS guaranteed.
